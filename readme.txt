== Description ==
Cloecloud CLI adds command palette actions and a productivity dashboard to WordPress.

== Installation ==
1. Upload the plugin files to the /wp-content/plugins/cloecloud-cli/ directory.
2. Activate the plugin through the Plugins screen.
